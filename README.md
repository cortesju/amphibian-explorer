# Colombia Amphibian Explorer

Interactive web map cataloguing 24 amphibian species across Colombia, integrating GBIF occurrence data, IUCN conservation status, and temporal filtering to visualize biodiversity distribution.

## What it shows

- **Species occurrence points** from GBIF for 24 amphibian species, classified by IUCN Red List status (Critically Endangered → Least Concern)
- **Temporal filtering** to explore how recorded occurrences shift across decades
- **Species cards** with conservation status, range description, and observation counts
- **Choropleth layer** showing department-level species richness

## Tech stack

- JavaScript
- GBIF occurrence API
- IUCN Red List categories

## Run locally

Open `index.html` in a browser. No build step required.
